# Assessment Evidence

This folder is reserved for genuine screenshots and logs captured from the project environment.

## Evidence checklist
- [ ] GitHub Actions successful CI run.
- [ ] Pytest output showing all automated tests passing.
- [ ] Ruff lint output.
- [ ] Intentional failure script and non-zero exit code.
- [ ] Docker Compose status showing API and database health.
- [ ] /health and /ready responses.
- [ ] Deployment using v2 and rollback using v1.
- [ ] Docker image list showing both version tags.

Only include evidence actually captured. Redact secrets and personal information.
